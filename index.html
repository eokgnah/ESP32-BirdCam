Update

Nur die Anwendung aktualisieren. Bootloader und Partitionstabelle bleiben unverändert.

  • Für bereits eingerichtete BirdCam mit dem v0.4.x Dual-OTA-Partitionslayout.
  • Die Firmware wird in beide OTA-App-Slots geschrieben, damit der aktuell ausgewählte Slot keine Rolle spielt.
  • Kein absichtliches Full-Chip-Erase.
Web Serial wird von diesem Browser nicht unterstützt.

Browser: Verwende einen Desktop-Browser mit Web Serial (z. B. Chrome oder Edge) und öffne diese Seite über HTTPS, etwa über GitHub Pages.
